# Design Review Thinking Guide

> **Purpose**: 确保在设计阶段进行深度审查，避免"做了再想"的陷阱。

---

## 为什么需要设计审查？

**大多数架构返工来自"设计阶段没想清楚"**：

- 术语模糊 → 前后端对不齐 → 接口返工
- 没考虑备选方案 → 选了次优实现 → 后面重构
- 没检查一致性 → 新功能与旧系统冲突 → 修bug修到崩溃
- 没考虑 UI/UX 规范 → 上线后可用性问题 → 紧急修复

**设计审查的成本远低于代码返工的成本。**

---

## 设计审查的两个维度

| 维度 | 何时触发 | 负责技能 | 产出 |
|------|----------|----------|------|
| **UI 设计审查** | 任务涉及前端/UI/界面 | `ui-ux-pro-max` | 设计系统推荐 + UX 审查报告 |
| **架构设计审查** | 所有任务（始终触发） | `grill-with-docs` | 术语对齐 + ADR + 架构审查报告 |

---

## 自动触发规则

```
任务类型判断
  │
  ├─ 含 UI/前端关键词？
  │   ├─ 是 → Phase 2a (UI 设计审查) + Phase 2b (架构设计审查)
  │   └─ 否 → Phase 2b (架构设计审查) only
```

**UI 触发关键词**：frontend、前端、UI、界面、页面、组件、样式、布局、dashboard、仪表盘、landing page、落地页、website、网站、mobile app、移动应用、React、Vue、Next.js、Tailwind、shadcn/ui、React Native、Flutter

## 使用方式

### 全自动流水线（推荐）

```bash
/costrict-autopilot <任务描述>
```

流水线自动执行所有阶段，无需手动调用任何子技能。

### 单独触发

```bash
# 仅 UI 设计审查
/ui-ux-pro-max <设计需求>

# 仅架构设计审查
/grill-with-docs <PRD 或设计文档路径>
```

## 设计审查清单

在进入实现前，确认以下检查点：

### 架构设计审查 (grill-with-docs)

- [ ] 所有关键术语在 CONTEXT.md 中已有精确定义
- [ ] 领域关系已经过边界场景压力测试
- [ ] 每个架构选择有明确的 trade-off 分析
- [ ] 难以逆转的决策已生成 ADR
- [ ] PRD 中的声明与代码库实际状态一致
- [ ] 术语模糊/过载问题已被解决

### UI 设计审查 (ui-ux-pro-max)

- [ ] 设计系统已生成（风格、调色板、字体、间距）
- [ ] 可访问性检查通过（对比度、焦点、键盘导航）
- [ ] 触摸交互达标（44px 目标、8px 间距）
- [ ] 性能策略明确（图片优化、懒加载、虚拟化）
- [ ] 布局响应式方案覆盖关键断点
- [ ] 动效方案尊重 prefers-reduced-motion
- [ ] 表单有完整的校验/错误/提交状态设计
- [ ] 导航模式清晰（≤5 底部项、可预测返回）

## 常见反模式

| 反模式 | 后果 | 正确做法 |
|--------|------|----------|
| 跳过设计审查直接写代码 | 设计问题在实现后才暴露，返工成本高 | 先审查再实现 |
| 术语不精确就开始实现 | 前后端理解不一致，接口对不齐 | grill-with-docs 精确化术语后再写代码 |
| 每个决策都生成 ADR | ADR 泛滥，重要决策被淹没 | 只有满足三条件（难以逆转+缺少上下文会困惑+做过取舍）才生成 ADR |
| UI 不做可访问性审查 | 上线后有合规风险，用户体验差 | ui-ux-pro-max 自动检查 Priority 1-2 |
| CONTEXT.md 写成技术文档 | 术语表被实现细节淹没，失去参考价值 | CONTEXT.md 只放术语定义，实现细节放 spec |

## 与其他思维指南的关系

- **Code Reuse Thinking Guide**：在实现阶段考虑复用 → **本指南在设计阶段先审查方案再实现**
- **Cross-Layer Thinking Guide**：数据跨层流转 → **本指南的架构审查会挑战跨层设计决策**
- **TDD Workflow Guide**：红-绿-重构循环 → **本指南确保进入 TDD 前设计方案已经过审查**

---

**核心理念**：设计阶段花 30 分钟审查，节省实现阶段 3 小时的返工。
