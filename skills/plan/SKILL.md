# /plan — 拆解编码子任务

## 概述

委托 planner agent，从 PRD 文档、技术方案和架构决策中产出独立可编码的子任务列表。按垂直切片拆分，确保每个子任务可独立编码和测试。子任务按优先级排序并标记依赖关系，无依赖的子任务可并行执行。

对应完整流水线 Phase 4。

## 执行流程

### Step 1: 读取输入文档

收集全量输入：

- **PRD 文档**（Phase 1 产出）：需求范围、验收标准、实现步骤
- **技术方案文档**（Phase 3 产出）：系统架构、模块设计、数据模型、技术选型
- **ADR**（来自 Phase 3）：架构决策记录
- **UI 设计审查报告**（Phase 2 产出，如有）：UI/UX 设计建议

### Step 2: 委托 planner agent 拆解

委托 **oh-my-costrict:planner** agent，基于输入文档产出子任务列表。拆解原则：

#### 垂直切片原则

每个子任务应当是一个完整的功能切片，从前端到后端（如适用），而非按技术层拆分。

- **好的拆法**："实现用户登录功能（含前端表单 + 后端验证 + Token 管理）"
- **不好的拆法**："实现用户控制器"、"实现用户服务层"、"实现用户数据访问层"

#### 子任务粒度

每个子任务应满足：
- **可独立编码**：单一开发者可在合理时间内完成（通常 1-3 小时）
- **可独立测试**：有明确的验收条件，可独立验证
- **有明确产出**：代码文件、测试文件等具体交付物

#### 依赖关系标记

为每个子任务标记依赖：
- **无依赖**：可立即开始，可与其他无依赖子任务并行
- **依赖 [子任务 N]**：需等待指定子任务完成后方可开始
- **软依赖**：建议在某某之后做，但不阻塞

### Step 3: 输出子任务列表

输出结构化的子任务列表：

```markdown
# 编码子任务列表

## 规划信息
- 任务目标：<PRD 标题>
- 总子任务数：N
- 可并行的子任务数：N
- 预计总耗时：约 X 小时

## 依赖关系图
[Task 1] ─── [Task 3] ─── [Task 5]
[Task 2] ─┘              └── [Task 6]
[Task 4] ─── [Task 7]

## 子任务清单

### [Task 1] <子任务标题> 🔵 可并行
- **描述**：<清晰的实现描述，包含涉及的文件/模块>
- **输入**：依赖的 PRD 章节 / 设计文档章节
- **验收条件**：
  - [ ] <可验证的条件 1>
  - [ ] <可验证的条件 2>
- **预计产出文件**：
  - `src/path/to/file1.ts`
  - `tests/path/to/file1.test.ts`
- **依赖**：无
- **可并行**：是

### [Task 2] <子任务标题> 🔵 可并行
- **描述**：<清晰的实现描述>
- **输入**：...
- **验收条件**：
  - [ ] ...
- **预计产出文件**：...
- **依赖**：无
- **可并行**：是

### [Task 3] <子任务标题> 🔴 依赖 Task 1
- **描述**：<清晰的实现描述>
- **输入**：...
- **验收条件**：
  - [ ] ...
- **预计产出文件**：...
- **依赖**：Task 1（需要用户模型定义）
- **可并行**：否

## 并行执行计划
### 第一波（无依赖，所有可并行）
- Task 1: <标题>（预计 X 小时）
- Task 2: <标题>（预计 X 小时）
- Task 4: <标题>（预计 X 小时）

### 第二波（依赖第一波完成）
- Task 3: <标题>（依赖 Task 1）
- Task 7: <标题>（依赖 Task 4）

### 第三波（剩余任务）
- Task 5: <标题>（依赖 Task 3）
- Task 6: <标题>（依赖 Task 3, Task 7）
```

## 使用方式

```bash
# 从 workflow 流水线自动触发（Phase 4）
/workflow 实现用户认证系统
# → Phase 1-3 完成后自动进入 Phase 4

# 独立调用
/plan docs/prd/user-auth.md

# 指定多个输入
/plan docs/prd/user-auth.md docs/design/architecture.md
```

## 注意事项

- 委托 planner agent，不要自行拆解子任务
- 必须按垂直切片拆分，禁止按技术层拆分
- 每个子任务必须有明确的验收条件
- 依赖关系必须标注清楚，无依赖的子任务标记"可并行"
- 子任务描述必须足够清晰，让 executor 可以独立完成编码
- 所有输出使用中文
